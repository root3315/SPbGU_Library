# Электронная библиотека СПбГУ

Прототип интерфейса: каталог с поиском и фильтрами, страница книги, читалка, личная полка, светлая и тёмная темы. Сайт статичный, данные демонстрационные. Прототип не является официальным сайтом университета.

## Запуск

Нужен Python 3:

```bash
python tools/serve.py
```

Сайт откроется на http://localhost:8765. Сервер отключает кеш, поэтому правки видны после обновления страницы. Через `file://` сайт не заработает: браузер не загружает ES-модули с диска.

## Структура

```
prototype/
  index.html        оболочка страницы
  styles.css        токены и стили
  js/
    main.js         запуск и глобальные события
    router.js       адрес, смена экранов, прокрутка, фокус
    nav.js          состояние навигации
    library.js      единственный доступ к данным книг
    data.js         демо-данные
    store.js        localStorage
    format.js       помощники без состояния
    components.js   обложка и плитки книг
    screens/        по файлу на экран
tools/
  serve.py          локальный сервер без кеша
```

## Как расширять

- **Новый экран:** файл в `js/screens/` и строка в `ROUTES` в `router.js`. Экран возвращает `{ title, html, bind(signal) }`.
- **Настоящие данные:** заменить реализацию в `library.js`, остальной код к данным напрямую не обращается.
- **Сканы обложек:** задать книге поля `image` и `color`. Цвет корешка и задней стороны берётся из `color`.
- **Обработчики на `document`:** вешать с `{ signal }`, чтобы они снимались при смене экрана.

Шифры, число страниц и доступность книг условные.
