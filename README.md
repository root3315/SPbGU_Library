# Электронная библиотека СПбГУ

Электронная библиотека СПбГУ: каталог изданий с поиском и фильтрами, страница книги с объёмной обложкой, страницы из сканов, личная полка, светлая и тёмная темы. Сайт статичный, работает на нативных ES-модулях без сборки и зависимостей, бэкенда нет.

## Запуск

Нужен Python 3:

```bash
python tools/serve.py
```

Сайт откроется на http://localhost:8765. Сервер отключает кеш, поэтому правки видны после обновления страницы. Через `file://` сайт не заработает: браузер не загружает ES-модули с диска.

## Структура

```
prototype/
  index.html        оболочка страницы
  styles.css        токены и стили
  js/
    main.js         запуск и глобальные события
    router.js       адрес, смена экранов, прокрутка, фокус
    nav.js          состояние навигации
    library.js      единственный доступ к данным книг
    flipbook.js     книга с перелистыванием
    data.js         каталог изданий
    store.js        localStorage
    format.js       помощники без состояния
    components.js   обложка и плитки книг
    screens/        по файлу на экран
tools/
  serve.py          локальный сервер без кеша
```

## Как расширять

- **Новый экран:** файл в `prototype/js/screens/` и строка в `ROUTES` в `router.js`. Экран возвращает `{ title, html, bind? }` и получает `{ id, params, signal }`. Пункт меню добавляется в `index.html`.
- **Настоящие данные:** сначала сделать `library.js` асинхронным и разделить загрузку и отрисовку в `router.js`, затем заменить реализацию.
- **Сканы обложек:** задать книге поля `image` и `color`. Цвет корешка и задней стороны берётся из `color`.

## Правила кода

- Экраны получают книги только через `library.js`.
- Обработчики на `document` и `matchMedia` вешаются с `{ signal }`, чтобы сниматься при смене экрана.
- Состояние каталога хранится в адресе, поэтому ссылка и кнопка «Назад» возвращают ту же выборку.
- Значения подставляются в разметку через `esc()`.
- Экраны не импортируют роутер, общее состояние лежит в `nav.js`.

## Дизайн

- Тонированный холст, белые мягкие карточки, короткие фразы вместо виджетов.
- Акцент `#9f2d20` и PT Serif взяты с сайта университета, интерфейс на Golos Text, заголовки на Manrope.
- Без капс-подписей, пилюль, цветных рамок и свечений.
- Книга в покое стоит ровно и поворачивается при наведении. На устройствах без наведения повёрнута только книга на её странице.
- Толщина книги зависит от числа страниц, пропорция обложки 2 к 3. Снимки обложек лежат в `covers/`, страницы в `scans/`. Без снимка обложка собирается из названия: цвет по разделу, рисунок по языку.
- У каждого издания открываются страницы из скана. Полных текстов пока нет.
- Смены состояния плавные, сдвигов макета нет, `prefers-reduced-motion` учитывается.
- Проверять на ширине от 320 до 2560 px, в светлой и тёмной темах.

## Публикация

Сайт публикуется из папки `prototype/` на GitHub Pages при пуше в `main`. В настройках репозитория источником Pages должен быть GitHub Actions. Тексты книг и обложки публикуются только при подтверждённых правах на них.

Шифры, число страниц и доступность книг условные.
